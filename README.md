# Systems of Thought — Personal Portfolio

Portfolio site for Rushil Reddy Yaragonda, presenting projects through a systems-thinking lens.

## Analysis

- **Core experience:** narrative landing page, project showcase, project-specific visuals, active-section navigation, and contact/link configuration.
- **Technical approach:** React + TypeScript + Vite with custom CSS and reusable visual components.
- **Portfolio value:** the central presentation layer for the project portfolio and the intended deployment at `https://rushilreddy.tech/`.
- **Current health:** production build and TypeScript check pass. ESLint reports two existing issues: irregular whitespace and an unused callback index.

## Run locally

```bash
npm install
npm run dev
```
